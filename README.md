### 1. Cement Industry Engineering
End-to-end design and optimization for pyroporocessing, grinding, and material handling systems:
- **Project Engineering**: Feasibility studies, Techno-Economic Assessments, Conceptual Engineering, and Front-End Engineering Design (FEED).
- **Plant Layout & General Arrangement (GA)**: Complete 3D layout development, equipment lists, and technical datasheets.
- **Heavy Platework Engineering**: Process gas ducting, transfer chutes, dedusting ductwork, baghouse layouts, cyclones, and transition hoppers.
- **CFD Aerodynamic Optimization**: Rotary kiln burner aerodynamics, calciner combustion modeling, cyclone preheater thermal flow, clinker cooler aeration, and separator efficiency.
- **Structural FEA**: Static and dynamic verification of rotary kiln components, ball mill foundations, stacker reclaimers, silos, and conveyor galleries.

### 2. Mining & Mineral Processing
High-efficiency designs engineered to resist abrasion, material wear, and hydrodynamic stress:
- **Plant Layout & Flow Development**: Crushing stations, screening buildings, beneficiation circuits, and stockpile handling systems.
- **Material Handling Platework**: Bulk transfer chutes engineered via Discrete Element Modeling (DEM) to minimize material degradation and impact wear.
- **Mine Ventilation & Dedusting CFD**: Airflow dynamics through tunnels, transfer points, crushing circuits, and pneumatic transport lines.
- **Hydraulic & Slurry Analysis**: Hydrocyclone separation dynamics, tailings slurry transport, and piping hydraulic head loss evaluations.
- **Structural Integrity**: Dynamic vibration and fatigue analysis on vibrating screens, crushers, and heavy storage bins.

### 3. Oil & Gas (Upstream & Downstream)
Robust engineering for high-pressure, high-temperature, and hazardous industrial environments:
- **Upstream Engineering**: Concept development, mechanical equipment design, modular skids, and process simulation.
- **Downstream Refining & Petrochemicals**: FEED packages, 3D piping routing in AVEVA E3D / AutoCAD Plant 3D, and civil/structural packages.
- **Pipe Stress & Flexibility Analysis**: Rigorous CAESAR II modeling calculating thermal expansion, code stress compliance (ASME B31.3), nozzle loading on pumps/turbines, and spring support schedules.
- **Equipment Design**: Pressure vessels (ASME Section VIII Div 1 & 2), storage tanks (API 650/620), and heat exchanger nozzle validation.

## 💻 Repository & Web Platform Architecture

The repository serves both as the corporate technical portfolio and the digital client interface for VQube Technologies. Designed for ultra-high speed, enterprise accessibility, and search engine dominance.

### Architecture Highlights
- **Core Technology**: Native Semantic HTML5, Modular Vanilla CSS3, and ES6+ JavaScript (zero heavy framework runtime overhead).
- **Design Aesthetic**: Minimalist warm monochrome palette (`#FAF6F2`, `#162B49`, `#111111`), custom typography via Adobe Typekit & Google Fonts (`sizmo`, `Geist`, `Newsreader`), fluid layout containers, and subtle micro-animations.
- **PWA Service Worker (`sw.js`)**: Implements dual caching strategy (Cache-First for static assets, Stale-While-Revalidate for HTML), providing sub-50ms repeat page loads and seamless offline resilience.
- **Enterprise SEO & Structured Data**: Complete Schema.org JSON-LD graph (`Organization`, `WebSite`, `FAQPage`, `Person`) enabling Google rich snippets and knowledge graph indexing.

## 🚀 Local Development & Deployment Guide

### Prerequisites
Because the platform is engineered with zero-dependency native web standards, no compilation or bundler toolchain (Webpack/Vite/npm) is strictly required to run or test the site.

### Running Locally

#### Option 1: Python HTTP Server (Recommended)
```bash
# Python 3.x
python -m http.server 8080

# Access in browser at: http://localhost:8080
```

#### Option 2: Node.js `serve` or `live-server`
```bash
# Using npx (no permanent installation required)
npx -y serve . -p 8080

# Or with live reloading:
npx -y live-server --port=8080
```

#### Option 3: VS Code / Cursor IDE Extension
Right-click on `index.html` and choose **"Open with Live Server"**.

### Verifying Service Worker & PWA Caching
1. Open DevTools in Google Chrome or Microsoft Edge (`F12` or `Ctrl+Shift+I`).
2. Navigate to **Application > Service Workers**.
3. Confirm `sw.js` is registered with status **Activated and is running**.
4. Check **Application > Cache Storage > vqube-perf-v2** to inspect cached static assets.
5. In the Network panel, toggle **Offline** mode to verify full offline accessibility.
